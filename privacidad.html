Privacidad del chat

Esta página explica qué pasa con lo que escribes en el chat con Patu, el asistente de este portfolio. Es un proyecto personal: cuento exactamente lo que hace, no un texto genérico.

Quién es el responsable

Jordi Patuel Pons. Contacto: chatbot.info@jordipatuel.com.

Qué se envía y adónde

Cada pregunta que escribes se envía a un servicio de Cloudflare (Workers y Workers AI) para generar la respuesta. Patu es una inteligencia artificial: puede equivocarse y no sustituye a hablar con Jordi.

Qué se guarda y durante cuánto tiempo

  • El texto de tu mensaje y la respuesta se guardan 30 días, para revisar la seguridad del asistente y ver qué se intenta con él. Un borrado automático diario los elimina a partir de entonces; las copias de seguridad de Cloudflare conservan la base de datos 7 días más y luego desaparecen.
  • Esos mensajes se guardan sin ningún dato que te identifique: ni tu dirección IP ni un identificador de visitante. Lo único que los acompaña es un número aleatorio de conversación (generado en tu navegador, agrupa los mensajes de una misma charla), la fecha y hora exactas y una etiqueta de cómo se clasificó la respuesta (normal, rechazada o bloqueada). Por eso no escribas datos personales.
  • Para limitar el uso se calcula un identificador anónimo a partir de tu dirección IP (en IPv6, de su prefijo), el día y una clave secreta que solo conoce el servidor. Ese identificador cambia cada día y su contador se borra al día siguiente. La IP no se guarda en la base de datos del chat. El límite es de 20 mensajes por conexión y día (no por persona) y existe además un tope diario global para todo el chat, que puede detenerlo antes.

Comprobación anti-bots

Para distinguir personas de programas automáticos se usa Cloudflare Turnstile. Se carga solo cuando abres el chat, no al entrar en la página. Este sitio no guarda nada en tu navegador salvo la preferencia de tema claro/oscuro. Para esa comprobación, el servidor envía tu dirección IP a Cloudflare Turnstile. Turnstile funciona en un iframe de Cloudflare y puede usar el almacenamiento de tu navegador para sus propios fines anti-bots, según la política de Cloudflare, no de este sitio.

Registros técnicos de Cloudflare

El servidor tiene activados los registros técnicos de Cloudflare Workers (decisión mía). Pueden incluir datos de la conexión, como la dirección IP, y Cloudflare los conserva unos días según su propia política.

Cómo pedir el borrado

Como las conversaciones se guardan sin identificarte, no puedo encontrar las tuyas por mi cuenta: escríbeme a chatbot.info@jordipatuel.com con un fragmento del texto que escribiste y borraré esa conversación. En cualquier caso, todo se elimina a partir de los 30 días.

Esto es un resumen honesto de un proyecto personal, no asesoramiento legal.
